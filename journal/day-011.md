# Day 011 - JavaScript Variables (let, const, var)

## Lesson - JS fundamentals, let/const/var differences

What happened:

- Today I learned how let, const, and var differ in declaration, reassignment, and scope.

Mistake made along the way (or things I found confusing):

- I was confused about why var behaves differently inside blocks.
- I was unsure when to use let instead of const.

Key takeaway:

- Use const by default, let when reassignment is needed, and var mainly for older code.
